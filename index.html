rclone WRK

rclone WRK is a private OAuth client. Its owner uses it to connect the open-source rclone tool, running on the owner's own Linux server, to the owner's own Google Drive accounts.

It is not a public service. There is no sign-up, and it is not offered to anyone else.

How rclone WRK handles Google user data is described in the privacy policy.

Maintained by GitHub user akuluckynugrohoaji-sys.
